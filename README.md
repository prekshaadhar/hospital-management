## Aarogya Hospital Management System
A hospital management web application built using Flask and MySQL.

## Features
- Appointment Booking
- Health Checkup Booking
- Doctor Search
- Admin Dashboard
- Patient Management

## Technologies Used
- Python Flask
- MySQL
- HTML
- CSS

## How to Run
Import `database.sql` into MySQL, then:

pip install -r requirements.txt

python app.py
